# Roadmap

The roadmap is directional and may change as the project is tested against more real-world libraries.

## v0.4.x — Interactive Net Generation

- [x] Component analysis by designator
- [x] Visible-pin extraction
- [x] Multifunction pin parsing
- [x] Engineer-controlled function selection
- [x] Semantic net-name preview
- [x] Configurable prefix
- [x] Per-pin YES / NO generation
- [x] Custom function entry
- [x] Adjustable Before / After wire margins
- [x] Equal-length Net Label bank

## v0.5.x — Parser and Naming Profiles

- [ ] Expanded device-family recognition
- [ ] User-defined naming profiles
- [ ] Configurable interface numbering
- [ ] Saved user preferences
- [ ] Improved token classification
- [ ] Additional parser test cases

## v0.6.x — Project Context

- [ ] Existing-net detection improvements
- [ ] Project-level naming analysis
- [ ] Conflict reporting
- [ ] Reusable rule sets
- [ ] Component-role metadata

## Research Direction

- [ ] Datasheet-assisted pin interpretation
- [ ] Function recommendation with explicit engineer approval
- [ ] Machine-readable design-intent model
- [ ] PCB constraint generation
- [ ] Placement assistance
- [ ] Routing assistance
- [ ] AI-assisted EDA workflows

## Non-Goal for Current Releases

Phoenix is not currently intended to perform fully autonomous schematic design or PCB routing.
