# Compatibility

Phoenix Net Generator is implemented in Altium Designer DelphiScript and relies on schematic interfaces such as:

- `SchServer`
- `ISch_Document`
- `ISch_Component`
- `ISch_Pin`
- `ISch_Wire`
- `ISch_NetLabel`

## Current Status

The project targets contemporary Altium Designer DelphiScript environments. Compatibility across all historical or future Altium Designer versions has not been validated.

## Reporting Compatibility Problems

Please include:

- Altium Designer version
- Windows version
- exact script error text
- highlighted source line, if available
- whether the error occurs during Analyze or Generate
- a minimal pin-name example when parser-related

Do not attach proprietary schematic files unless you have permission to publish them.
